Management System Default Data

Predefined text templates for Management System fields to speed up data entry and keep content consistent.

Key features

  • Pick a template directly next to the target field (no copy/paste needed).
  • Extend a chosen template by inserting additional text with one click.
  • Save the current field value as a new reusable default template.
  • Works with Html/Text fields in mgmtsystem.action and mgmtsystem.root_cause_analysis.
  • Keeps manuals and incident records uniform across the organization.

Where it applies

  • Action description (mgmtsystem.action: description).
  • Root cause analysis sections: incident description, symptoms & consequences, root cause, corrective actions, preventive actions, lessons learned, primary/secondary causes, contributing factors.

Dependencies

  • default_data (template storage and utilities)
  • mgmtsystem_info_security_manual_nen7510
